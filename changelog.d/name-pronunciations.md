### Added

- Set how the narrator says a name right from the reader: select it (long-press) and tap Pronounce, type how it
  sounds ("NEF-iss", "say-SHAHN": hyphens between syllables, the stressed one in capitals, or any spelling that sounds
  right), hear it with the voice that reads the novel, and save it for this novel or for all novels. "Nephis's" and
  "NEPHIS" are covered too; the page text never changes.
- Stress respellings work with every voice: Nephis and the Apple voice read the plain form ("Nef-iss"), Kokoro gets
  exact phonemes with the stress where the capitals were. A novel's own entry wins over the one for all novels.

### Changed

- The pronunciation list (Listen player › Voice › Pronunciations, Settings › Voices): tap a word to change it; ▶ plays
  a stress respelling the way narration reads it.
